# TATTOO STENCIL FREE

Aplicación FastAPI para mejorar imágenes y generar stencils artísticos de tatuaje.

## Railway

El repositorio incluye un `Dockerfile` listo para Railway. Railway debe recibir la variable secreta:

- `OPENAI_API_KEY`

No guardes claves API en el repositorio.

Health check disponible en `/api/health`.
