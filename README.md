# TATTOO STENCIL v58

Cambios principales de esta versión:
- aviso emergente de pago al cargar la primera imagen;
- controles Suave/Equilibrada/Fuerte sustituidos por una barra de fuerza con − / +;
- posterización simplificada a una sola barra de detalle con − / +;
- textos y avisos solicitados eliminados;
- títulos de vista previa cambiados a “Dale click para descargar”;
- mapa Detallado ajustado para conservar más zonas medianas y grandes de la posterización sin recuperar microzonas;
- el stencil continúa usando la posterización y su mapa de guías como referencia geométrica, sin pegar el mapa bruto encima del resultado final.
